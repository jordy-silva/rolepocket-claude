# RolePocket

Use your career evidence to build a focused job search with RolePocket. This plugin bundles three skills and a remote connection to your RolePocket workspace:

- Build or update a reusable career-context document.
- Assess saved opportunities and save recommendations when requested.
- Prepare truthful application materials, including a DOCX CV when Claude can create, render and deliver documents.

This is a Claude compatibility preview. Account connection and document delivery are still being verified. Please check the setup guide and contact support if you need help.

Start with the [marketplace setup guide](https://github.com/jordy-silva/RolePocket-claude).

Connected job workflows require RolePocket workspace access. Your Claude subscription is separate. The career-context skill can work without a RolePocket connection, using documents you provide to Claude.

The plugin can read saved jobs, capture a job when requested, save requested recommendations and record completed application preparation. It does not submit applications, contact employers, mark jobs applied, manage billing or download documents stored in RolePocket. Career documents and generated CVs stay in the assistant unless you separately choose to upload them.

Use the plugin's Connectors tab to connect RolePocket and complete its sign-in and permission flow. Credentials are never included in this package. Confirm the connected account before reading or saving jobs.
